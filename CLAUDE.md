# Project Conventions

## Stack

- Front end: **Vite + React + TypeScript (strict) + Tailwind**.
- Back end: **FastAPI (Python)**.
- Tools: **MCP servers via FastMCP over Streamable HTTP**.
- Runtime model: **Gemini** on Vertex AI, with **Pro** for hard turns and **Flash** for routine turns.
- Model adapter: access models only through an `LLMClient` adapter; a `ClaudeClient` may exist behind the same interface for A/B comparison.
- Data: **Firestore + Cloud Storage + Vertex embeddings**.

## Hard rules

- All game mechanics resolve through MCP tools. The model never invents HP totals, dice results, initiative, or deterministic state.
- MCP tools are **deterministic and side-effecting**.
- There are **no generative tools**. Battle maps are uploaded by the user, never generated by the AI.
- Narration and creative text live only in the orchestrator's model call.

## Ruleset

- This project targets **D&D 2024 (5.5e)**.
- The rules RAG corpus is **SRD 5.2** (the Creative Commons release of the 2024 rules) plus any 2024 sourcebooks.
- Use 2024 terminology in the app and contracts, including the exhaustion **level track 0–6** and the 2024 condition list.

## Contract

- `contracts/` is the **single source of truth** for shared domain types and API surfaces.
- Never define a domain type locally that diverges from `contracts/types.ts`.
- The front end imports from `contracts/`; the back end mirrors the same contract with Pydantic models when needed.
